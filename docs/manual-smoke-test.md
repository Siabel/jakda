# 운영 배포 전 직접 점검표

아래 항목은 `release` 병합과 운영 배포 전에 로컬 화면에서 확인합니다. 실제 데이터와 섞이지 않도록 테스트용 일정과 거래 제목 앞에 `[테스트]`를 붙이고 점검이 끝나면 삭제합니다.

## 로그인과 계정

- 기존 계정으로 로그인할 수 있다.
- 잘못된 비밀번호에는 로그인 실패 안내가 나온다.
- 프로필에서 닉네임과 실명을 수정할 수 있다.
- 새로고침 후에도 로그인과 수정한 프로필이 유지된다.

## 일정과 스케줄러

- 오늘 화면과 캘린더에서 일정을 하나씩 추가한다.
- 종료 시간이 시작 시간보다 빠르면 저장되지 않는다.
- 등록한 일정이 하루 스케줄러에 한 번만 표시된다.
- 일정 수정과 삭제가 가능하다.
- 예상 지출이 있는 일정을 완료하고 실제 지출로 전환한다.
- 같은 일정의 실제 지출은 추가 생성이 아니라 수정으로 열린다.

## 기록과 가계부

- 하루 기록을 추가·수정·삭제한다.
- 감정을 여러 개 저장하고 캘린더에는 가장 강한 감정 하나가 보이는지 확인한다.
- 수입과 지출을 각각 등록하고 카테고리 목록이 구분되는지 확인한다.
- 거래 메모와 반복 거래 설정을 저장한다.
- 월별 합계와 통계가 등록한 금액에 맞게 갱신되는지 확인한다.

## 장소와 지도

- 일정에서 `서울숲`을 검색한다.
- 검색 결과 선택 시 장소명과 주소가 함께 입력된다.
- 저장한 일정의 지도 링크가 네이버 지도 검색으로 열린다.

## 백업과 모바일

- 설정에서 JSON 백업 파일을 내려받는다.
- 백업 파일에 일정, 거래, 감정 일기, 하루 기록이 포함되어 있는지 확인한다.
- 모바일 너비에서 화면이 가로로 밀리지 않는다.
- 하단 메뉴, 더보기, 프로필, 일정 추가 버튼을 사용할 수 있다.
- 설치된 PWA에서는 설치 안내가 다시 나타나지 않는다.

## 완료 조건

- 브라우저 오류 화면이나 콘솔 오류가 없다.
- 저장 후 새로고침해도 데이터가 유지된다.
- 테스트 데이터가 모두 정리되었다.
- 위 항목이 통과한 뒤에만 `refactor/cleanup`을 `release`에 병합하고 태그를 생성한다.
